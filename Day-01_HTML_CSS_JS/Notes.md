# Day 1 Notes

## What is Full Stack Development?

Full Stack Development is the process of developing both the frontend and backend of a web application.

### Frontend

The frontend is the part of the application that users can see and interact with.

Technologies:

- HTML
- CSS
- JavaScript

### Backend

The backend processes user requests, performs application logic, and communicates with databases.

Examples:

- Node.js
- Express.js
- Python
- Java
