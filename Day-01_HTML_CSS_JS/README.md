# Day 1 – HTML, CSS & JavaScript Basics

## 📌 Objective

Understand the fundamentals of web development by building and improving a simple login page using HTML, CSS, and JavaScript.

---

## 📚 Topics Covered

### HTML

- HTML5 Document Structure
- `<head>` and `<body>`
- `<input>`
- `<button>`
- `<p>`
- `id`
- `placeholder`
- Labels

### CSS

- External CSS
- Basic Styling
- Layout
- Input Styling
- Button Styling

### JavaScript

- DOM
- document
- getElementById()
- .value
- textContent
- Functions
- if Statement
- Logical AND (&&)
- addEventListener()
